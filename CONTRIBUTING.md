# Contributing to Nexora

Thank you for your interest in Nexora.

Nexora is proprietary, source-available software maintained by its copyright holder. You are welcome to report bugs and propose improvements using **GitHub Issues**.

## Reporting a bug

Open a **Bug Report** issue. Include a concise description, steps to reproduce, expected and actual behavior, environment details, and relevant logs or screenshots. Do not post secrets, credentials, or personal information.

## Suggesting a feature

Open a **Feature Request** issue. Describe the problem, your proposed solution, and why it would be useful.

## Code changes and pull requests

Pull requests and unsolicited code contributions are **not accepted by default**. Please open an issue first. Only the maintainer or explicitly authorized contributors may implement and publish changes. Written authorization and agreed contribution terms are required before submitting code.

The maintainer decides whether, when, and how to implement requests. An issue does not guarantee implementation.
